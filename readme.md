# Bibliotheque PHP POO PDO

Projet de gestion de bibliothèque en PHP 8 + POO + PDO + MySQL.

## Fonctionnalités
- CRUD Livres, Auteurs, Catégories
- Connexion PDO sécurisée avec try/catch
- Structure MVC simple

## Installation
1. Créer une BDD `bibliotheque` dans phpMyAdmin
2. Modifier `config/Database.php` : host, user, pass
3. Lancer : http://localhost/PHP2ndsemestre/Bibliotheque/

## Arborescence
- `classes/` : Modèles Livre, Auteur, Categorie
- `config/` : Connexion BDD
- `includes/` : Header, Footer
